# Política de Privacidade — Coroa das Lágrimas

**Última atualização: Julho de 2026**

## 1. Introdução

O aplicativo **Coroa das Lágrimas** ("App") é um aplicativo devocional católico desenvolvido para orientar rezas e promover a devoção a Nossa Senhora das Lágrimas. Respeitamos sua privacidade e nos comprometemos a ser transparente sobre como tratamos seus dados.

Esta Política de Privacidade explica quais informações coletamos, como as usamos e seus direitos.

## 2. Informações que Coletamos

### 2.1 Identificadores de Publicidade (Google Mobile Ads)

O App integra a plataforma **Google Mobile Ads** (AdMob) para exibir anúncios. Para isso, coletamos:

- **Google Advertising ID**: um identificador único e anônimo fornecido pelo Google para fins de publicidade personalizada
- **Dados de anúncios**: interações com anúncios (exibições, cliques)

**Finalidade**: personalizar anúncios relevantes e gerar receita para manter o aplicativo gratuito.

**Controle**: você pode resetar seu Google Advertising ID nas Configurações de privacidade do seu dispositivo Android a qualquer momento. Isso não bloqueia anúncios, mas impede rastreamento entre apps.

### 2.2 Dados de Uso do App

O App **não coleta** dados pessoais como nome, e-mail, localização, contatos ou histórico de navegação. Todos os dados sobre suas orações e metas são armazenados **localmente no seu dispositivo** via AsyncStorage, não são enviados para nossos servidores.

### 2.3 Dados de Diagnóstico (Expo Updates)

O framework Expo pode coletar dados técnicos anônimos de desempenho do app (tempo de carregamento, crashs) para melhorar estabilidade — **sem rastrear conteúdo de orações ou atividade do usuário**.

## 3. Como Usamos as Informações

| Dado | Finalidade |
|---|---|
| Google Advertising ID | Personalizar anúncios; gerar receita |
| Dados de anúncios | Relatórios de desempenho de campanhas (Google) |
| Dados técnicos (Expo) | Detecção de bugs; melhoria de performance |

## 4. Compartilhamento com Terceiros

Compartilhamos **apenas** o Google Advertising ID com:

- **Google Ads / AdMob**: para exibição e personalização de anúncios
- **Google Analytics** (opcional, se habilitado em atualizações futuras): para análise de uso agregada

**Não compartilhamos** dados de orações, metas ou qualquer informação sensível.

## 5. Retenção de Dados

- **Dados locais** (orações, metas): armazenados no seu dispositivo indefinidamente; você pode deletar a qualquer momento desinstalando o app ou limpando dados do app nas Configurações
- **Google Advertising ID**: gerenciado pelo Google; você pode resetá-lo conforme descrito acima
- **Registros de anúncios**: Google os retém por 90-180 dias conforme sua Política de Privacidade

## 6. Segurança

O App não transmite dados sensíveis para a internet. Todos os dados de oração e metas são armazenados localmente com proteção padrão do Android. Para anúncios, a comunicação com Google AdMob usa criptografia HTTPS.

## 7. Direitos do Usuário (LGPD e GDPR)

Sob a Lei Geral de Proteção de Dados (LGPD — Brasil) e GDPR (EU), você tem direito a:

- **Acessar** seus dados: verifique os dados armazenados no app localmente
- **Deletar** seus dados: desinstale o app ou limpe dados nas Configurações do Android
- **Revogar consentimento**: desative ads personalizados nas Configurações de privacidade do seu dispositivo
- **Portar dados**: seus dados locais são seus; exportar via cópia manual

Para exercer direitos relacionados a Google Ads, acesse [Google Privacy & Terms](https://policies.google.com/privacy).

## 8. Crianças

O App **não é direcionado a menores de 13 anos**. Não coletamos intencionalmente dados de crianças. Se você é responsável por uma criança, controle o acesso via controles parentais do Android.

## 9. Alterações a Esta Política

Podemos atualizar esta política. Notificaremos mudanças significativas através de:
- Novo aviso no app
- Este documento atualizado no GitHub/repositório

Seu uso contínuo após alterações significa aceitação.
